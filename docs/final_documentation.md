# Academic Risk Prediction and Virtual Tutor

## Overview
This project predicts student academic risk using IA1, IA2, assignment performance, and attendance, then provides personalized learning recommendations through a virtual tutor workflow.

## Features
- Academic risk prediction
- Risk-based learning resources
- Personalized tutoring prompts
- Virtual tutor responses
- Student profile testing
- Response quality evaluation
- Student context retrieval
- Personalized follow-up guidance
- Integrated tutor workflow
- Tkinter interface
- Scenario validation
- Final demonstration

## Risk Model
IA1 = 30%, IA2 = 30%, Assignment = 20%, Attendance = 20%.

High risk: score below 50.
Medium risk: score from 50 to below 70.
Low risk: score 70 or above.

## Final Demonstration
The final demonstration successfully generated a 53.9 academic score, Medium risk classification, Arrays as the weak topic, learning resources, a study plan, a short-term goal, and a follow-up question.

## Technologies
Python, Tkinter, Git, GitHub, and an LLM-oriented tutoring workflow.

## Conclusion
The project demonstrates an end-to-end academic-risk prediction and personalized virtual-tutor workflow.
