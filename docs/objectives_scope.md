# Objectives and Scope

## Aim
Develop a Python-based prototype combining academic risk estimation and syllabus-grounded tutoring.

## Objectives
1. Prepare a structured assessment dataset.
2. Explore and preprocess the data.
3. Train Logistic Regression and Random Forest classifiers.
4. Evaluate model performance on held-out data.
5. Build a Streamlit interface.
6. Retrieve syllabus passages for tutor grounding.
7. Provide stepwise learning recommendations.
8. Document privacy, fairness, and limitations.

## Scope
### In scope
Synthetic data, assessment features, model comparison, dashboard, syllabus PDF/TXT retrieval, optional LLM API, testing and documentation.

### Out of scope
Automated grading, disciplinary decisions, high-stakes use, unsupported claims of accuracy, and live institutional-system integration.
